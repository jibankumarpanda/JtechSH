# Emails Manual

Manual rules and procedures for email triage.

## Rules

See `EMAILRULES.md` for the full rule set.

## Quick Reference

### Auto-Archive (Rule 1)
- Machine auto-replies (QQ, out-of-office)
- One-line unknown tasking with no context

### Never Archive
- Security-related emails (CVE, GHSA, incident, breach)
- Human emails requiring a response
- Billing or time-sensitive notifications

### Observe Only
- Unknown messages without clear action required
- Newsletters (archive candidates, not auto-archive)
