# Twitter Mentions

Manual tracking and rules for Twitter/X mention moderation.

## Moderation Rules

### Auto-Block
- Crypto pump / token spam
- AI-generated slop / engagement bait
- Scam links / phishing
- Known spam accounts

### Keep
- Genuine bug reports
- Genuine questions about Triger.sh
- Feature requests
- Constructive feedback

### Ignore
- Retweets / quotes with no new content
- General mentions with no actionable content
